# Visual Art AI — Brand + Design System v3

**Signal → Discovery → Match.**

La producción usa cuatro escenarios visuales para evitar monotonía sin perder sistema: Editorial Light, Ink Dark, Interface Canvas e Immersive.

Acento principal: Signal Vermilion #D94A2B. Apoyos: Ink #141413, Paper #FBFAF7, Coral #F56F56, Cyan #58B7CD y Green #2E8B57.

Arquitectura: foundations → primitive tokens → semantic tokens → components → pattern families → templates → art direction.

Producción:
- /design-system.css: foundations, componentes, patrones, responsive y artículos.
- /brand/visual-art-ai-design-system.css: símbolo y motion.
- /site.js: interacción.

Regla: ninguna decisión visual importante debe existir solo porque “se veía bien en esa pantalla”.
