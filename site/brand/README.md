# Visual Art AI — Brand System v1

## Idea
**Signal → Discovery → Match.** La identidad representa una señal que entra al ecosistema de búsqueda, es interpretada y termina en un punto de descubrimiento.

## Marca
- Wordmark: **VISUAL ART AI**
- La A se dibuja como glifo vectorial propio, geométrico y coherente con el peso óptico del resto del wordmark.
- Descriptor: **Visibilidad en la nueva búsqueda**
- El símbolo no es un “sparkle de IA”: representa búsqueda, señal, entidad y coincidencia.

## Color principal
**Signal Vermilion — `#D94A2B`**

Se eligió para abandonar el morado genérico asociado a numerosas interfaces de IA. Es cálido, fuerte, visible sobre fondos claros y oscuros y contrasta conceptualmente con los colores de Google, ChatGPT, Gemini y Perplexity sin intentar imitarlos.

### Tokens
- `--brand-accent: #D94A2B`
- `--brand-accent-hover: #B9381F`
- `--brand-accent-bright: #FF7254`
- `--brand-accent-soft: rgba(217,74,43,.10)`
- Ink: `#171715`
- Paper: `#F8F7F3`

## Uso
El acento se reserva para:
- señal / descubrimiento;
- CTA principal;
- estados activos;
- énfasis editorial breve;
- trazas y animaciones del símbolo.

No usarlo como relleno decorativo masivo.

## Movimiento
El movimiento de la marca tiene cuatro actos:
1. aparece una señal;
2. recorre la órbita;
3. alcanza el nodo;
4. se produce un destello de match.

Duración base: **5.2 s**. Sin movimiento continuo agresivo. Respeta `prefers-reduced-motion`.
