# Pack de Prompts para Redes Sociales

30 prompts probados y optimizados para generar contenido auténtico en tus redes. Cada prompt está diseñado para mantener tu voz y adaptarse a tu nicho.

---

## Instrucciones de uso

1. Reemplaza los campos en `[corchetes]` con tu información
2. Añade tu "declaración de voz" al inicio de cada sesión
3. Itera: si el resultado no es exacto, pide ajustes específicos

**Plantilla de voz (añadir antes de usar cualquier prompt):**
```
Mi voz: [directo/cercano/profesional/etc.]
Mi nicho: [tu área]
Mi audiencia: [descripción breve]
No usar: [palabras o frases que no son tuyas]
```

## Categoría 1: Educación y valor (10 prompts)

### P01 — Post educativo de 3 puntos
```
Escribe un post de Instagram sobre [tema] que enseñe 3 cosas que la mayoría no sabe.
Formato: gancho potente + 3 puntos numerados + CTA.
Tono: [tu tono]. Máximo 300 palabras.
```

### P02 — Hilo de LinkedIn con datos
```
Crea un hilo de LinkedIn de 5 tweets sobre [tema].
El primero debe ser el hook con una afirmación contraintuitiva.
Incluye al menos 2 datos o estadísticas reales.
Cierra con una pregunta para generar comentarios.
```

### P03 — Carrusel: error común + solución
```
Genera el copy para un carrusel de Instagram de 6 slides:
Slide 1: El error que comete el 90% de [audiencia] con [tema]
Slide 2-4: Los 3 errores más comunes (uno por slide)
Slide 5: La solución correcta
Slide 6: CTA
```

### P04 — Post "lo que nadie te dice"
```
Escribe un post sobre [tema] con el ángulo "lo que nadie te dice sobre [subtema]".
Menciona 4 verdades incómodas pero útiles. Sin filtros corporativos.
```

### P05 — Tutorial paso a paso
```
Crea un post explicando cómo [tarea/proceso] en 5 pasos.
Cada paso debe tener un nombre memorable y una descripción de 1-2 líneas.
Incluye qué herramienta usar en cada paso.
```

### P06 — Definición simplificada
```
Explica [concepto técnico/complejo] como si se lo explicaras a alguien que nunca
ha escuchado de [tu industria]. Sin jerga. Con una analogía cotidiana.
```

### P07 — Mitos vs Realidad
```
Escribe un post de LinkedIn con formato "Mito vs Realidad" sobre [tema].
5 mitos comunes + la realidad de cada uno.
```

### P08 — Lista de recursos
```
Genera un post de Instagram con mis [N] herramientas/recursos favoritos para [objetivo].
Para cada uno: nombre + para qué sirve + por qué lo recomiendo.
```

### P09 — Lección aprendida
```
Escribe un post sobre la lección más importante que aprendí después de [experiencia].
Estructura: contexto → error/desafío → la lección → cómo aplicarla.
```

### P10 — Predicción o tendencia
```
Escribe un post con mi opinión sobre [tendencia en mi industria].
Incluye: qué está pasando, por qué importa, cómo prepararse. Tono opinativo y seguro.
```

## Categoría 2: Conexión y storytelling (10 prompts)

### P11 — Historia personal + lección
```
Ayúdame a estructurar esta historia personal: [describe tu experiencia].
Formato: situación inicial → problema → momento de quiebre → resolución → lección.
```

### P12 — Behind the scenes
```
Escribe un post de "detrás de escena" sobre [un proceso/proyecto tuyo].
Muestra lo que la gente no ve. Sé honesto sobre los desafíos.
```

### P13 — Post de fracaso (relatable)
```
Escribe un post sobre cuando [algo salió mal].
No hacer catarsis — hacer que el fracaso sea útil para la audiencia.
```

### P14 — "Cuando era [X], pensaba que..."
```
Crea un post con el formato "Cuando era [versión anterior de ti], pensaba que [creencia]".
Contrasta con lo que sabes ahora. Debe resonar con [tu audiencia objetivo].
```

### P15 — Día en la vida
```
Describe un día típico en mi vida como [tu rol] de forma que muestre el valor de
mi trabajo y conecte con [audiencia]. No hagas una lista de horas — cuenta una historia.
```

### P16 — Post de agradecimiento auténtico
```
Escribe un post agradeciendo a [hito/audiencia/colaborador] que no suene corporativo.
Debe ser específico, concreto y genuino.
```

### P17 — Pregunta que genera debate
```
Genera 5 preguntas para posts de LinkedIn que generen debate productivo sobre [tema].
Deben tener respuestas divididas pero no ser polarizantes negativamente.
```

### P18 — Antes y después de aprender X
```
Escribe un carrusel de "antes y después" de que [audiencia] aprenda/implemente [tu método].
4 slides de antes y 4 de después. Concreto y específico.
```

### P19 — El momento que cambió mi perspectiva
```
Escribe un post sobre el momento que cambió cómo pienso sobre [tema].
Estructura narrativa, no lista. Primera persona.
```

### P20 — Carta a mi yo de hace X años
```
Escribe un post en formato "carta a mi yo de hace [X] años" sobre [tema].
Consejos concretos, tono honesto y cercano.
```

## Categoría 3: Conversión y CTA (10 prompts)

### P21 — Post de oferta sin ser agresivo
```
Escribe un post presentando [tu oferta/servicio] sin sonar a vendedor.
Enfoca en el problema que resuelve. Incluye un CTA suave pero claro.
```

### P22 — Objeciones frecuentes
```
Mi oferta: [descripción]. La objeción más frecuente: "[objeción]".
Escribe un post que aborde esta objeción de frente, honestamente.
```

### P23 — Testimonio storytelling
```
Tengo este testimonio de cliente: [testimonio].
Conviértelo en un post narrativo de impacto sin exagerar ni inventar.
```

### P24 — Comparación con la alternativa
```
Escribe un post comparando [tu solución] vs [la alternativa común].
No hagas la alternativa ver mal — muestra cuándo cada opción tiene sentido.
```

### P25 — Caso de uso específico
```
Escribe un post mostrando cómo [tipo de persona específica] puede usar [tu producto/servicio]
para resolver [problema concreto]. Muy específico, nada genérico.
```

### P26 — Urgencia sin falsedad
```
Escribe un post comunicando que [oferta/lanzamiento] está disponible por tiempo limitado.
Sin frases de vendedor barato. Honesto sobre por qué hay límite.
```

### P27 — Post de FAQ
```
Las 5 preguntas más frecuentes sobre [tu oferta/servicio] son: [lista].
Escribe un carrusel de LinkedIn respondiendo cada una brevemente.
```

### P28 — El costo de no actuar
```
Escribe un post que haga reflexionar a [audiencia] sobre el costo de NO resolver
[problema que tu solución resuelve]. Sin miedo ni presión — con honestidad.
```

### P29 — Prueba social con datos
```
Tengo estos resultados de clientes: [datos].
Conviértelos en un post creíble y concreto que no suene a fanfarronería.
```

### P30 — CTA para comunidad/lista
```
Escribe un post invitando a [audiencia] a [unirse a tu newsletter/comunidad/recurso gratuito].
El beneficio debe estar claro en las primeras 2 líneas.
```
