# Pack de Prompts para Presentaciones

20 prompts organizados en 4 fases del proceso de creación de presentaciones.

---

## Fase 1: Estrategia y Estructura (P01–P05)

**P01 — Definir el mensaje central**
```
Tengo que presentar sobre [tema] ante [audiencia].
El contexto es: [descripción breve]
El tiempo disponible es: [N minutos]

¿Cuál debería ser el único mensaje que me deben recordar al salir?
Dame 3 opciones de mensaje central y explica cuál recomiendas y por qué.
```

**P02 — Estructura completa de la presentación**
```
Crea la estructura de una presentación con estas características:
- Tema: [tema]
- Audiencia: [descripción con nivel de conocimiento]
- Duración: [N minutos]
- Objetivo: [qué deben hacer o decidir después]
- Principal objeción que van a tener: [cuál es]

Para cada slide: título + punto central + formato sugerido (texto/gráfico/imagen/tabla).
Máximo [N] slides.
```

**P03 — Anticipar objeciones**
```
Esta es mi presentación: [describe o pega el esquema]

Asume que la audiencia es escéptica. Lista las 5 objeciones más probables
que van a tener y en qué slide debería responder cada una.
```

**P04 — Hook de apertura**
```
Necesito abrir una presentación sobre [tema] para [audiencia].
Objetivo de la presentación: [qué quiero lograr]

Dame 3 opciones de apertura distintas:
1. Apertura con dato o estadística impactante
2. Apertura con pregunta al público
3. Apertura con historia corta (30 segundos)

Para cada una, escribe exactamente qué diría en los primeros 60 segundos.
```

**P05 — Cierre con call-to-action**
```
Mi presentación termina con el siguiente resumen: [pega tu slide de cierre actual]
El objetivo es que la audiencia [acción específica].

Crea un cierre que:
- Refuerce el mensaje central en 2 oraciones
- Haga una sola pregunta clara o proponga una acción concreta
- Sea memorable (puede usar una metáfora, pregunta retórica o afirmación fuerte)
```

## Fase 2: Contenido de las Slides (P06–P10)

**P06 — Convertir datos aburridos en historia**
```
Tengo estos datos: [pega los datos o describe]

Ayúdame a presentarlos como una historia con:
1. El problema que revelan estos datos
2. La causa principal
3. El impacto si no se actúa
4. La solución propuesta

Usa lenguaje simple, sin jerga técnica.
```

**P07 — Escribir los bullets de una slide**
```
El punto central de esta slide es: [mensaje]
El contexto previo en la presentación es: [qué dijo la slide anterior]

Escribe 3-4 bullets concisos para esta slide.
Cada bullet: máximo 8 palabras.
Empiezas con verbo activo.
```

**P08 — Simplificar slide con demasiado texto**
```
Esta slide tiene demasiado texto:
[pega el contenido de la slide]

Mantén solo lo esencial para que la audiencia pueda:
1. Leer el título y el punto clave en 5 segundos
2. El orador explique el resto verbalmente

Versión simplificada:
```

**P09 — Título para cada slide**
```
Estos son los puntos clave que quiero comunicar en cada slide:
[lista tus puntos]

Escribe un título de máximo 6 palabras para cada uno.
El título debe comunicar el mensaje por sí solo,
sin necesidad de leer el contenido.
```

**P10 — Transiciones entre slides**
```
Mis slides van en este orden:
Slide A: [tema]
Slide B: [tema]
Slide C: [tema]

Escribe las frases de transición para pasar fluidamente entre cada slide.
Máximo 2 oraciones por transición.
Deben mantener el hilo narrativo.
```

## Fase 3: Adaptación de la Presentación (P11–P15)

**P11 — Adaptar nivel de detalle para la audiencia**
```
Esta presentación está diseñada para [audiencia original]:
[describe o pega el esquema]

Cómo debería adaptarla para [nueva audiencia]:
- ¿Qué simplificarías o eliminarías?
- ¿Qué agregarías o profundizarías?
- ¿Qué lenguaje deberías cambiar?
```

**P12 — Versión corta de una presentación larga**
```
Tengo una presentación de [N] slides para [N minutos].
Me piden hacer una versión de [N] minutos.

Aquí está mi estructura actual: [lista las slides]

¿Qué slides eliminarías, cuáles fusionarías, y cuáles son inamovibles?
```

**P13 — Convertir presentación en documento escrito**
```
Esta es la estructura de mi presentación:
[pega el esquema o el texto de las slides]

Convierte esto en un documento de lectura de máximo [N] páginas
que tenga coherencia narrativa y pueda enviarse por email.
```

**P14 — Generar Q&A anticipado**
```
Mi presentación es sobre: [tema y resumen]

Genera las 8 preguntas más probables del público después de la presentación,
con respuestas concisas de máximo 3 oraciones cada una.
Incluye 2 preguntas incómodas o difíciles.
```

**P15 — Notas del orador**
```
Esta es la slide [N] de mi presentación:
Título: [título]
Contenido: [bullets o texto]

Escribe las notas del orador para esta slide:
- Qué decir (90 segundos aproximadamente)
- Qué no decir (qué es obvio o redundante)
- Una anécdota o ejemplo para hacerla más concreta (opcional)
```

## Fase 4: Revisión y Mejora (P16–P20)

**P16 — Revisor de coherencia narrativa**
```
Aquí está el flujo de mi presentación:
[lista los títulos de todas las slides en orden]

¿Hay alguna slide que interrumpe el flujo narrativo?
¿El orden lógico es el correcto?
¿Hay algún salto lógico que necesite una slide de transición?
```

**P17 — Evaluar la presentación como audiencia escéptica**
```
Esta es mi presentación: [esquema o texto]
Actúa como un miembro de la audiencia que llega con escepticismo y me enfrenta.

¿En qué punto pierdo credibilidad?
¿Qué afirmación necesita más evidencia?
¿Qué parte se siente incompleta o poco convincente?
```

**P18 — Mejorar el storytelling**
```
Esta es la versión actual de mi presentación: [esquema]
La presentación funciona en lo técnico pero falta emoción.

¿Cómo agregaría un elemento de storytelling o narrativa humana
sin cambiar el mensaje central?
Dame 2 opciones: una con historia personal y otra con caso de estudio.
```

**P19 — Checklist de la presentación**
```
Tengo esta presentación: [pega el esquema o los títulos]

Evalúa con sí/no:
1. ¿Hay un mensaje central claro?
2. ¿Cada slide tiene exactamente un punto?
3. ¿El hook de apertura capta atención?
4. ¿El cierre tiene un call-to-action claro?
5. ¿La estructura tiene un flujo lógico?
6. ¿El lenguaje es apropiado para la audiencia?

Para cada "no", sugiere cómo corregirlo.
```

**P20 — Script de presentación oral**
```
Esta es mi presentación: [esquema con bullets]
Duración objetivo: [N] minutos
Tono: [formal/conversacional]

Escribe el script completo de lo que diría al presentar,
slide por slide, incluyendo transiciones entre cada una.
Debe sonar natural al hablar, no a texto leído.
```
