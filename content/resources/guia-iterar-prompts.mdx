# Cómo Iterar Prompts

La mayoría de personas prueba un prompt una vez, no le gusta el resultado, y concluye que "la IA no sirve para esto".

El problema no es la IA. Es que los mejores resultados raramente salen al primer intento.

---

## El ciclo de iteración

```
Prompt inicial → Resultado → Diagnóstico → Ajuste → Mejor resultado
```

Cada ciclo toma 30-60 segundos. En 3-5 ciclos obtienes resultados profesionales.

---

## Las 4 palancas del prompt

Cuando el resultado no es lo que esperabas, ajusta una de estas palancas:

### 1. Contexto
Agrega más información sobre la situación.

❌ "Escribe un email para mi cliente"
✅ "Escribe un email para mi cliente (empresa mediana, sector retail, llevamos 2 años trabajando juntos) informando un retraso de 3 días en su entrega por problemas logísticos externos"

### 2. Formato
Especifica exactamente cómo quieres la respuesta.

❌ "Dame ideas de contenido"
✅ "Dame 5 ideas de contenido en este formato: [Gancho] + [Tema] + [Formato sugerido (carrusel/reel/post)]"

### 3. Tono y estilo
Describe con ejemplos, no solo con adjetivos.

❌ "En tono informal"
✅ "En tono como si le escribiera a un colega cercano. Ejemplo de mi estilo: 'Oye, necesito contarte algo que puede afectar el proyecto...'"

### 4. Restricciones
Dile qué NO hacer.

❌ No especificar
✅ "No uses: frases corporativas, 'espero que este email te encuentre bien', oraciones de más de 20 palabras"

---

## Comandos de refinamiento

Cuando tienes un resultado que va en la dirección correcta pero necesita ajustes:

```
"Está bien, pero hazlo más [corto/formal/directo/específico]"

"Mantén la estructura pero cambia el tono a [tono]"

"La primera parte está perfecta. Reescribe solo la conclusión para que sea más [ajuste]"

"Genera 3 variaciones de este párrafo manteniendo el mismo mensaje"

"¿Qué información adicional necesitas para mejorar esto?"
```

---

## El prompt de meta-iteración

Cuando no sabes cómo mejorar el resultado:

```
El resultado que me diste no es lo que necesito.
El problema específico es: [describe qué no funciona]
Lo que yo esperaba era: [describe tu expectativa]

¿Qué información adicional necesitas de mí para dar un mejor resultado?
Hazme 3 preguntas específicas.
```

---

## Señales de que tu prompt necesita más contexto

| Señal | Qué agregar |
|-------|-------------|
| Respuesta muy genérica | Más detalles sobre tu situación específica |
| Tono incorrecto | Ejemplo real de tu estilo |
| Formato no útil | Especifica el formato exacto que necesitas |
| Demasiado largo | "En máximo N palabras" |
| Demasiado corto | "Desarrolla cada punto con al menos 2 oraciones" |
| Ignora algo importante | "Asegúrate de incluir [elemento crucial]" |

---

## Guardar prompts que funcionan

Cuando un prompt produce exactamente lo que necesitas, guárdalo como plantilla en:
- Notion (base de datos de prompts)
- Google Keep o Apple Notes
- Un documento de "Mi biblioteca de prompts"

Estructura para guardar:
```
NOMBRE: [nombre descriptivo]
CATEGORÍA: [email / reporte / análisis / contenido]
CONTEXTO: [cuándo usarlo]
PROMPT: [el prompt completo]
RESULTADO: [descripción del resultado esperado]
FECHA: [para saber si necesita actualización]
```

---

> **La regla más importante:** Si un prompt no funciona a la primera, no descartes la herramienta — refina el prompt. La IA es tan buena como las instrucciones que le das.
