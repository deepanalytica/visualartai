# Plantilla Brief Creativo

Usa esta plantilla para estructurar cualquier proyecto creativo. Puedes completarla tú mismo o usar el prompt de IA al final para generarla a partir de una conversación.

---

### 1. CONTEXTO Y ANTECEDENTES

**¿Qué hace la marca?**
_Descripción en 2-3 oraciones de la empresa/marca._

**¿Cuál es la situación actual?**
_¿Qué está pasando que genera la necesidad de este proyecto?_

**¿Qué ha funcionado antes? ¿Qué no?**
_Referencias de comunicaciones anteriores._

_¿Qué debe lograr este proyecto? Ej: "Generar [X] leads", "Aumentar reconocimiento de marca", "Lanzar producto [X]"_

**Objetivos secundarios (máx. 2):**
1. _______________
2. _______________

## Prompt de IA para generar este brief

Si tienes poco tiempo, usa este prompt para que la IA complete el brief a partir de una descripción:

```
Quiero hacer un brief creativo para este proyecto:
[describe el proyecto en 3-5 oraciones]

Hazme las preguntas necesarias para completar cada sección de este brief:
1. Contexto y antecedentes
2. Objetivo del proyecto
3. Audiencia
4. Mensaje central
5. Mandatorios
6. Deliverables

Hazme una sección a la vez y espera mi respuesta antes de continuar.
Al final, genera el brief completo en formato limpio.
```

---

## Checklist de aprobación del brief

Antes de enviarlo al equipo creativo:

- [ ] ¿El objetivo es específico y medible?
- [ ] ¿La audiencia está bien definida?
- [ ] ¿El mensaje central cabe en una oración?
- [ ] ¿Los mandatorios son claros y completos?
- [ ] ¿Los deliverables tienen formato y cantidad especificados?
- [ ] ¿El brief fue revisado por el cliente/stakeholder?
