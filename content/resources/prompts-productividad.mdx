# Pack de Prompts para Productividad

25 prompts organizados en 5 categorías para recuperar horas de trabajo cada semana.

---

## Categoría 1: Reportes y Análisis (P01–P06)

**P01 — Resumen ejecutivo de datos**
```
Analiza estos datos y entrega un resumen ejecutivo de 150 palabras máximo:
- Los 3 números más importantes
- Qué cambió vs período anterior (con %)
- 1 riesgo y 1 oportunidad

Datos: [pega aquí]
```

**P02 — Generación de insights accionables**
```
A partir de estos datos, genera 3 insights siguiendo el formato:
OBSERVACIÓN: [qué está pasando]
IMPLICACIÓN: [qué significa para el negocio]
ACCIÓN: [qué hacer esta semana]

Datos: [pega aquí]
```

**P03 — Reporte de estado de proyecto**
```
Crea un reporte de estado de proyecto con este formato:
- Resumen ejecutivo (2 oraciones)
- Logros de la semana (3-5 bullets)
- Próximas tareas (3-5 bullets con fecha)
- Riesgos y bloqueos
- Semáforo general (verde/amarillo/rojo) y justificación

Información del proyecto: [describe situación actual]
```

**P04 — Dashboard de métricas en texto**
```
Convierte estos números en un resumen visual de métricas con emojis indicadores:
🟢 Si supera el objetivo
🟡 Si está cerca del objetivo
🔴 Si está por debajo

Métricas del período [fecha]:
[lista tus métricas y objetivos]
```

**P05 — Análisis de causa raíz**
```
Tengo este problema: [describe el problema]
Estos son los síntomas que observo: [lista síntomas]

Aplica el método de los 5 Por Qué para encontrar la causa raíz.
Termina con 2 acciones correctivas concretas.
```

**P06 — Comparativa de opciones**
```
Necesito comparar estas opciones para tomar una decisión:
Opciones: [lista las opciones]
Criterios que importan: [lista los criterios con su peso si lo tienes]
Restricciones: [presupuesto, tiempo, recursos]

Crea una tabla comparativa y recomienda la mejor opción con justificación.
```

## Categoría 2: Comunicación Escrita (P07–P12)

**P07 — Email de solicitud directa**
```
Escribe un email para solicitar [qué necesitas] a [quién].
Contexto: [situación]
Tono: [formal/informal]
Urgencia: [alta/media/baja]
Incluye: asunto, cuerpo y cierre.
```

**P08 — Respuesta a una queja o reclamo**
```
Recibí esta queja: [describe o pega el mensaje]
La situación real es: [tu versión]
Puedes ofrecer: [qué está en tu poder hacer]

Escribe una respuesta que:
1. Reconozca el problema (sin admitir culpa innecesariamente)
2. Explique qué pasó brevemente
3. Proponga una solución concreta
4. Sea empática pero profesional
```

**P09 — Seguimiento sin ser molesto**
```
Envié este mensaje/propuesta [hace N días] y no he recibido respuesta.
Mi mensaje original: [resumen o copia]

Escribe un seguimiento amable que:
- Recuerde el contexto brevemente
- Haga una sola pregunta clara
- No suene a presión
- Sea corto (máx. 5 oraciones)
```

**P10 — Comunicado interno de cambio**
```
Necesito comunicar este cambio a mi equipo: [describe el cambio]
Razón del cambio: [por qué]
Impacto en el equipo: [qué cambia para ellos]
Fecha efectiva: [cuándo]

Crea un comunicado que:
- Sea directo y claro
- Anticipe las preguntas más obvias
- Termine con próximos pasos concretos
```

**P11 — Propuesta de proyecto breve**
```
Necesito proponer [idea/proyecto] a [quién].
El problema que resuelve: [problema]
Mi solución propuesta: [descripción breve]
Recursos que necesito: [tiempo, dinero, personas]
Resultado esperado: [KPIs o beneficios]

Escribe una propuesta de 1 página máximo que sea fácil de aprobar.
```

**P12 — Minuta de reunión**
```
Esta reunión duró [N] minutos y se trataron estos temas:
[lista los temas discutidos en bullets]

Decisiones tomadas:
[lista las decisiones]

Genera una minuta formal que incluya:
- Asistentes (yo los completaré)
- Resumen de temas
- Decisiones y responsables
- Próximas acciones con fecha y dueño
```

## Categoría 3: Presentaciones y Documentos (P13–P17)

**P13 — Estructura de presentación ejecutiva**
```
Crea la estructura para una presentación de [N] slides sobre [tema].
Audiencia: [descripción]
Objetivo: [qué deben hacer o decidir después]
Tiempo disponible: [minutos]

Para cada slide: título + punto central + formato sugerido.
```

**P14 — Convertir bullet points en narrativa**
```
Tengo estos bullet points para una presentación:
[lista tus bullets]

Convierte esto en una narrativa fluida de 3-4 párrafos que:
- Tenga un argumento central claro
- Conecte los puntos con transiciones naturales
- Termine con una conclusión o llamada a la acción
```

**P15 — Resumen ejecutivo de documento largo**
```
Resume este documento en máximo 1 página (300 palabras):
- Propósito del documento (1 oración)
- 3-5 puntos clave
- Conclusiones o recomendaciones principales
- Próximos pasos (si aplica)

Documento: [pega aquí o describe]
```

**P16 — FAQ automático**
```
Basándote en este documento/proceso: [descripción o texto]

Genera las 8 preguntas más frecuentes que alguien tendría,
con respuestas claras y concisas (máx. 3 oraciones por respuesta).
```

**P17 — Checklist de proceso**
```
Describe este proceso de forma que alguien que nunca lo ha hecho pueda seguirlo:
Proceso: [descripción]
Audiencia: [nivel de experiencia]
Frecuencia: [con qué frecuencia se realiza]

Formato: checklist paso a paso con sub-pasos donde sea necesario.
Incluye: qué hacer si algo falla en cada paso crítico.
```

## Categoría 4: SOPs y Documentación (P18–P21)

**P18 — Convertir descripción en SOP**
```
Convierte esta descripción informal en un SOP profesional:
[describe el proceso en tus palabras]

Formato del SOP:
- Objetivo
- Frecuencia
- Responsable
- Prerrequisitos
- Pasos numerados (con detalle)
- Cómo verificar que está bien hecho
```

**P19 — Documentar proceso desde transcripción**
```
Tengo esta transcripción de mi descripción en voz del proceso:
[pega la transcripción]

Limpia el texto, elimina repeticiones, y conviértelo en SOP estructurado
con los pasos claros y numerados.
```

**P20 — Actualizar SOP existente**
```
Este es mi SOP actual: [pega el SOP]
Estos son los cambios que quiero incorporar: [describe los cambios]

Actualiza el SOP manteniendo el mismo formato,
marca con [NUEVO] o [MODIFICADO] los pasos que cambiaron.
```

**P21 — Onboarding de nuevo empleado/cliente**
```
Crea un documento de onboarding para [empleado/cliente nuevo] que describe:
- Qué encontrarán en los primeros [3/7/30] días
- Las 5 cosas más importantes que deben saber primero
- A quién contactar para cada tipo de consulta
- Los accesos y recursos que necesitarán
- Los primeros pasos concretos para empezar

Contexto de la empresa/servicio: [descripción breve]
```

## Categoría 5: Revisión y Mejora (P22–P25)

**P22 — Revisor de textos**
```
Revisa este texto y señala:
1. Errores gramaticales u ortográficos
2. Oraciones confusas o ambiguas
3. Palabras redundantes
4. Si el tono es consistente con [profesional/cercano/formal]

Texto: [pega aquí]

Entrega: el texto corregido + una lista de cambios realizados.
```

**P23 — Simplificador de jerga técnica**
```
Reescribe este texto para que lo entienda alguien sin conocimiento técnico:
[texto técnico]

Audiencia objetivo: [descripción]
Mantén el significado pero usa lenguaje cotidiano.
Máximo el mismo largo que el original.
```

**P24 — Devil's Advocate**
```
Esta es mi propuesta/plan: [describe]

Actúa como alguien escéptico y dame los 5 argumentos más fuertes
en contra de esta idea. Sé específico y directo.
Después dame cómo respondería yo a cada objeción.
```

**P25 — Revisión de prioridades**
```
Tengo estas tareas pendientes:
[lista tus tareas]

Considerando que [contexto: deadline, objetivo del mes, recursos disponibles]:
1. Ordénalas por impacto/urgencia (matriz 2x2)
2. Identifica cuáles puedo delegar o eliminar
3. Dame mis top 3 para hoy
```
