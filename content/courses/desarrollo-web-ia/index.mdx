## Sobre este curso

La forma de construir aplicaciones web cambió de fondo. No en el sentido de "la IA escribe código por ti" — sino en el sentido de que el ciclo completo de desarrollo, desde la arquitectura hasta el deploy, ahora tiene un copiloto que elimina la fricción.

El problema es que la mayoría usa la IA de forma reactiva: le preguntan cosas, copian el código, y si no funciona, vuelven a preguntar. Sin sistema. Sin contexto. Sin aprovechar lo que realmente ofrecen herramientas como Claude Code, los MCP servers, y un CLAUDE.md bien construido.

Este curso enseña **el workflow profesional completo**: cómo dar contexto a Claude para que entienda tu proyecto desde el día 1, cómo conectarlo a tus herramientas (Notion, Supabase, Vercel, GitHub) via MCP, cómo estructurar prompts que eliminan la ambigüedad, y cómo tomar decisiones de diseño que no requieren ser diseñador.

El resultado: **apps bien construidas, bien diseñadas, en producción, en una fracción del tiempo**.

## Lo que construyes en el proyecto final

Una aplicación SaaS funcional con:
- Autenticación completa (login, register, reset password)
- Base de datos con RLS (cada usuario ve solo sus datos)
- Dashboard de usuario con datos reales
- Deploy automático en Vercel con preview environments
- Diseño cohesivo usando un sistema visual definido con IA
