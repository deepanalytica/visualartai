## La escala de realismo

No todas las imágenes "realistas" buscan lo mismo. Existe una escala:

```
Ilustración ── Arte digital ── Fotografía estilizada ── Fotografía documental ── Hiperrealismo
     ↑                                                                                    ↑
"dibujado"                                                                    "no puedes decir
                                                                               si es real o no"
```

Cada punto tiene usos distintos y requiere distintas técnicas de prompt.

---

## Nivel 1: Fotografía estilizada (editorial)

**Para qué:** contenido de marca, redes sociales, catálogos creativos

**Lo que lo define:** coloring fuerte, composición deliberada, algo "demasiado perfecto" para ser casual. Sabes que es una foto profesional, pero hay intención artística evidente.

**Palabras clave:**
```
editorial photography, fashion photography, creative direction,
color grading, [nombre de fotógrafo editorial como referente],
Vogue-style, campaign photography
```

**Ejemplo:**
```
editorial product photography of a perfume bottle, warm amber lighting,
shallow depth of field, clean white marble surface,
color grading, professional studio, Canon 5D Mark IV, 85mm f/1.4
```

---

## Nivel 2: Fotografía documental / realista

**Para qué:** cuando quieres que parezca "encontrado", auténtico, no producido

**Lo que lo define:** imperfección intencional. Grano fotográfico, iluminación no perfecta, composición levemente imperfecta, momentos naturales.

**Palabras clave:**
```
documentary photography, candid photography, photojournalism style,
natural light, film grain, Kodak Portra 400, 35mm film,
imperfect, authentic moment, street photography
```

**Ejemplo:**
```
candid documentary photo of a person reading in a café,
natural window light, slight motion blur, film grain,
Fujifilm X-Pro3, 35mm f/2, Kodak Portra 400 emulation,
authentic, unposed
```

---

## Nivel 3: Hiperrealismo fotográfico

**Para qué:** cuando quieres que sea indistinguible de una foto real tomada por un humano. Máxima credibilidad.

**Lo que lo define:** detalles microscópicos, iluminación perfectamente coherente, poros de piel visibles, reflecciones físicamente correctas, profundidad de campo perfecta.

**Palabras clave:**
```
hyperrealistic photograph, photorealistic, 8K resolution,
ultra-detailed, pore-level detail, physically accurate lighting,
professional photography, shot on [cámara de alta gama],
macro detail, razor-sharp focus
```

**Ejemplo:**
```
hyperrealistic photograph of a woman's face, 35mm, golden hour light
streaming through window, visible skin texture and pores,
catchlight in eyes, soft hair strands, photorealistic,
shot on Hasselblad X2D, 90mm f/3.2, ultra-detailed, 8K
```

---

## El hiperrealismo tiene una trampa

La Uncanny Valley: cuando algo se acerca mucho a lo real pero no llega, el cerebro lo detecta como "raro" — y es más perturbador que algo claramente artificial.

Esto pasa especialmente con:
- Caras humanas (ojos que no tienen vida, proporción levemente incorrecta)
- Manos (ya mencionado)
- Movimiento implícito (pelo que no cae naturalmente)

**Cómo evitar la Uncanny Valley:**
1. Usa ángulos donde la cara no sea el elemento central (3/4, perfil, alejado)
2. Agrega "imperfección" deliberada: `slight asymmetry, natural skin`, `human imperfection`
3. Luz que crea sombras — la luz plana revela las fallas del modelo
4. Profundidad de campo que "borra" las partes problemáticas (manos en bokeh)

## ¿Qué nivel necesitas?

| Uso final | Nivel recomendado |
|-----------|------------------|
| Post de Instagram (marca) | Editorial (Nivel 1) |
| Imagen de portada de curso | Editorial / Documental (1-2) |
| Foto de "caso de estudio" | Documental (Nivel 2) |
| Avatar o foto de perfil IA | Hiperrealista (Nivel 3) |
| Foto de producto para e-commerce | Editorial o Hiperrealista (1 o 3) |
| Imagen para anuncio | Hiperrealista (Nivel 3) |
| Moodboard de referencia | Cualquier nivel |

En el método Nano Banana, el nivel de realismo se define en el **Layer 3 (Técnica)** — el uso de cámara/lente específico y el tipo de fotografía activan el nivel correcto automáticamente.
