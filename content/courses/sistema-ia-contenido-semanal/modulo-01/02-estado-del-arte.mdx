# El estado actual: qué herramientas de IA realmente valen la pena

El ecosistema de IA para contenido está lleno de ruido. Cada semana aparece una herramienta nueva que promete revolucionar tu flujo de trabajo. La realidad: la mayoría son redundantes.

## El problema del "tool hopping"

Muchos creadores pasan más tiempo probando herramientas nuevas que creando contenido. El objetivo de este módulo es ayudarte a elegir **tu stack de IA definitivo** y quedarte con él.

## Las categorías que importan

### 1. Texto y estrategia
- **ChatGPT (GPT-4)** — el más versátil, ideal para brainstorming y redacción
- **Claude** — mejor para textos largos y mantener voz
- **Gemini** — integrado con Google, útil para investigación con fuentes

**Nuestra recomendación:** Elige uno como principal. Nosotros usamos Claude para textos de marca y ChatGPT para variaciones rápidas.

### 2. Imagen generativa
- **Midjourney** — el estándar para calidad fotorrealista y artística
- **DALL-E 3** — integrado en ChatGPT, cómodo para iteración rápida
- **Adobe Firefly** — si ya tienes Creative Cloud, excelente para assets de marca

### 3. Video
- **RunwayML** — el mejor para generación y edición con IA
- **CapCut** — para edición rápida con subtítulos automáticos
- **HeyGen** — avatares de IA si necesitas presentador virtual

### 4. Automatización
- **Make (Zapier)** — conexión entre plataformas
- **Notion AI** — si usas Notion para planificación

## El stack recomendado para empezar

Para el 90% de los creadores, este stack es suficiente:

```
ChatGPT o Claude → Texto y estrategia
DALL-E 3 o Midjourney → Creatividades
Canva → Diseño y composición final
CapCut → Video y reels
```

## Ejercicio de esta lección

Completa la **Hoja de mapeo de herramientas** (en recursos) con:
1. Qué herramienta usarás para texto
2. Qué herramienta usarás para imágenes
3. Qué herramienta usarás para video

No necesitas todas — elige según tu tipo de contenido predominante.
