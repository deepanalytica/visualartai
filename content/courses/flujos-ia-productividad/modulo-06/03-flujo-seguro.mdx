## El flujo de trabajo seguro

Incorporar IA a tu trabajo no es un interruptor que activas. Es un conjunto de hábitos que se construyen tarea por tarea.

El flujo seguro tiene 4 momentos:

```
1. ANTES: ¿Puedo/debo usar IA aquí?
2. DURANTE: ¿Qué información ingreso y qué no?
3. DESPUÉS: ¿Revisé el output antes de usar?
4. ACTUALIZACIÓN: ¿Aprendí algo que mejora mi proceso?
```

---

## El checklist antes de usar IA en una nueva tarea

Para cada tarea nueva (no las que ya tienes sistematizadas), hazte estas preguntas:

- [ ] ¿El output de esta tarea se puede verificar? (¿sé si la IA se equivocó?)
- [ ] ¿La información que voy a ingresar es apropiada según mi política?
- [ ] ¿Tengo el prompt correcto o necesito construirlo primero?
- [ ] ¿Hay un humano en el loop para revisar antes de usar el output?

Si la respuesta a cualquiera es "no estoy seguro", detente 5 minutos y resuélvelo antes de ejecutar.

## Casos de borde comunes

### Datos de clientes en reportes
**Situación:** tu reporte semanal incluye nombres y datos de clientes reales.
**Solución:** anonimiza antes de pegar ("Cliente A" en lugar del nombre real, o usa iniciales). El reporte generado funcionará igual.

### Información bajo NDA
**Situación:** el brief de un proyecto tiene información que no puede salir del equipo.
**Solución:** usa solo los elementos estructurales (tipo de proyecto, objetivos generales) y elimina los detalles sensibles antes de ingresar. O usa una versión enterprise del servicio con garantías de privacidad.

### Output de IA en documentos legales o financieros
**Situación:** usas IA para redactar un contrato, propuesta con valores reales, o reporte financiero.
**Solución:** doble revisión antes de enviar. La IA puede cometer errores en números, fechas o cláusulas. Sin excepción, verifica esos elementos manualmente.

### Credenciales en contexto
**Situación:** estás pidiendo ayuda para configurar una herramienta y tienes que describir tu setup.
**Solución:** nunca incluyas contraseñas, tokens, o API keys en el prompt. Describe el setup sin las credenciales reales.

## Lo que cambia al trabajar con IA

Con el tiempo, el flujo seguro deja de ser un checklist consciente y se convierte en instinto. Sabes qué tareas van directas a IA, cuáles necesitan preparación, cuáles requieren revisión doble.

Ese instinto se construye con la práctica de las semanas anteriores del curso.
