## El salto de datos a historia visual

El trabajo más tedioso de una presentación no es el diseño — es la estructura. Tomar datos crudos, decidir qué incluir, en qué orden, y cómo conectarlos en una narrativa.

La IA hace ese trabajo de síntesis en minutos.

---

## El flujo de datos a presentación

```
Paso 1: Recopilar los datos o contenido (5-10 min)
  → Junta los números, el reporte, o las ideas clave
  → No necesitas organizarlos — solo tenerlos

Paso 2: Generar la estructura con IA (10-15 min)
  → Usa el prompt de estructura para definir slides y mensajes clave

Paso 3: Generar el contenido de cada slide (15-20 min)
  → Genera títulos, bullets y notas del orador

Paso 4: Aplicar diseño (15-30 min)
  → En PowerPoint/Keynote/Canva, o herramienta automática

Paso 5: Revisar y ajustar (10-15 min)
  → Verifica coherencia, ajusta lo que no suena bien
```

---

## Prompt para convertir datos en presentación

```
Tengo estos datos / información:
[pega tus datos, informe, o puntos clave en bruto]

Genera la estructura de una presentación de [N] slides para:
- Audiencia: [descripción]
- Objetivo: [qué deben entender, sentir o decidir al terminar]
- Duración de la presentación: [N minutos]

Para cada slide:
1. Número de slide
2. Título (máx. 6 palabras, debe comunicar el mensaje solo)
3. Puntos clave (máx. 3 bullets de máx. 8 palabras cada uno)
4. Nota del orador (lo que se diría al presentar esta slide, 30-60 segundos)
5. Tipo de visual sugerido (dato, gráfico, imagen, tabla, etc.)
```

## Cuándo usar automático vs manual

**Usar generación automática cuando:**
- La presentación es interna o informal
- El tiempo es muy limitado
- El contenido es principalmente textual o basado en listas

**Hacer diseño manual (con estructura de IA) cuando:**
- Es una presentación de alta visibilidad (cliente, directivos, pitch)
- Tiene datos complejos que necesitan visualizaciones específicas
- Tu marca tiene guidelines estrictos de diseño

En ambos casos, la IA genera la estructura y el contenido — el diseño es la única variable.
